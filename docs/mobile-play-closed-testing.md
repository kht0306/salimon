# 살림온 0.3.10 비공개 테스트 업데이트

- 기존 Play Console 앱: `com.salimon.app`
- 표시 버전: `0.3.10`, versionCode: `15`
- 대상: Galaxy Z Fold5, Galaxy S25 Ultra
- 이번 추가 범위: 우리카드(우리WON카드) 앱의 일시불 정상 승인 알림
- 지원 본문 형식: `[일시불.승인(끝 4자리)]MM/DD HH:mm`, `결제금액원 / 누적:누적금액원`, `가맹점`
- 이번 전달은 배포 파일 준비까지이며, Play Console 업로드·제출은 사용자가 진행한다.
- 국민·우리카드 전체취소·부분취소, 카드 형식이 다른 알림은 지원하지 않는다.
- 실제 금융 알림 수신은 두 사용자 기기에서 확인해야 한다. 합성 표본 테스트가
  카드사·앱 버전별 실제 알림을 모두 검증한 것은 아니다.

## 파일 생성

기존 로컬 Gradle 릴리스 서명 설정을 사용한다. 키·비밀번호·환경변수 값을 문서나
채팅에 복사하지 않는다. 배포 파일에는 서명 키가 포함되지 않는다.

```bash
JAVA_HOME='/Applications/Android Studio.app/Contents/jbr/Contents/Home' \
ANDROID_HOME="$HOME/Library/Android/sdk" \
node apps/mobile/scripts/build-play-release.mjs
```

`dist/mobile/play-0.3.10-15/`에 다음 파일이 생성된다.

| 파일                           | 용도                                   |
| ------------------------------ | -------------------------------------- |
| `salimon-0.3.10-15.aab`        | Play Console 비공개 테스트에 업로드    |
| `salimon-0.3.10-15.aab.sha256` | AAB 파일 무결성 확인                   |
| `release-notes-ko-KR.txt`      | 변경사항 입력란에 붙여 넣기            |
| `release-manifest.json`        | 패키지·버전·업로드 인증서 SHA-256 확인 |
| `UPLOAD-AND-TEST.md`           | 이 업로드·실사용 검증 안내             |

체크섬 확인:

```bash
cd dist/mobile/play-0.3.10-15
shasum -a 256 -c salimon-0.3.10-15.aab.sha256
```

## 기존 비공개 테스트 업데이트

1. Play Console에서 기존 **살림온** 앱을 연다.
2. **테스트 및 출시 → 테스트 → 비공개 테스트**에서 기존 테스트 트랙을 연다.
3. 버전 15가 아직 사용되지 않았는지 확인한다. 이미 사용됐다면 `app.json`의
   versionCode를 더 높이고 다시 빌드한다. 기존 파일의 이름만 바꾸면 안 된다.
4. 새 버전에 AAB를 업로드한다. 서명 불일치 오류가 발생하면 기존 업로드 키 설정을
   확인한다. 임의로 앱 서명 키를 바꾸거나 새 앱을 만들지 않는다.
5. 업로드 인증서 SHA-256이 `release-manifest.json`과 같은지 확인한다.
   업로드 인증서와 Google Play 앱 서명 인증서는 서로 다를 수 있다.
6. `release-notes-ko-KR.txt` 내용을 변경사항에 입력하고 오류·경고를 검토한다.
7. 기존 앱 콘텐츠의 알림 접근 고지와 데이터 보안 답변이 현재 기능에 맞는지 확인한다.
   알림 원문·미확정 후보는 기기 안에서만 처리되며, 사용자가 확정한 거래는 서버에
   저장된다. 일반 대화나 문자 보관함 전체를 읽는 기능은 아니다.
8. 검토 후 **비공개 테스트 트랙**으로 출시한다. 프로덕션 트랙을 선택하지 않는다.
9. 기존 테스터 Google 계정과 참여 링크를 사용해 두 기기에서 업데이트한다.
   배포 검토·전파가 완료되기 전에는 업데이트가 보이지 않을 수 있다.

기존 alpha 트랙에서 확인한 링크:

- [테스트 참여](https://play.google.com/apps/testing/com.salimon.app)
- [Play Store에서 업데이트](https://play.google.com/store/apps/details?id=com.salimon.app)

기존 앱을 삭제하지 않고 Play Store에서 업데이트한다. 직접 설치한 APK를 사용 중인
기기는 Play 앱 서명과의 호환 여부를 먼저 확인한다. 서명 오류를 해결하려고 앱을
바로 삭제하면 로컬 미처리 후보가 사라질 수 있다.

## 기기별 설정

| 수신 경로        | 설정 → 결제 알림 후보함 → 지원 앱                 |
| ---------------- | ------------------------------------------------- |
| 국민카드 문자    | 실제 사용하는 삼성 메시지 또는 Google 메시지 선택 |
| 우리카드 알림톡  | 카카오톡 선택                                     |
| 우리카드 앱 알림 | 우리카드 선택                                     |

- 기존 사용자에게 새 수신 앱을 자동으로 켜지 않는다. 원하는 앱을 선택하고 설정을 저장한다.
- 우리카드 앱과 카카오톡에서 같은 결제가 모두 도착하면 후보가 각각 생길 수 있다.
  우리카드 앱 경로를 테스트할 때는 필요에 따라 카카오톡 수집을 끄고 한 경로를 사용한다.
- 알림 접근을 허용하고 등록 대상 가계부를 선택한다.
- 국민카드의 문자 앱 표시 이름이 단순히 ‘메시지’라면 앱 정보를 확인한다.
- 수집은 각 기기에서 수행한다. 상대방 휴대폰 알림을 본인 기기에서 직접 읽지 않는다.
- 카드 메시지 본문이 Android 알림에 포함되어야 한다. 채팅방에만 보이는 내용은
  자동으로 읽지 않는다. 오래된 채팅·문자 내역을 소급 수집하지 않는다.

## 실사용 확인표

테스트용 추가 결제는 필요 없다. 다음 정상 결제가 발생했을 때 확인한다.

- [ ] 업데이트 후 로그인과 기존 가계부가 유지된다.
- [ ] 새 수신 앱을 선택해 저장할 수 있다.
- [ ] 지원 앱에서 우리카드를 켜고 저장한 뒤 새 앱 승인 알림이 후보로 들어온다.
- [ ] 앱 승인금액 36,500원과 누적금액 410,632원을 혼동하지 않는다.
- [ ] 앱 알림의 승인시각, 가맹점, 우리카드 태그 및 카드 끝 4자리가 정확하다.
- [ ] 앱의 취소·부분취소·광고·여러 결제 묶음 알림을 후보로 등록하지 않는다.
- [ ] 우리카드 알림톡 후보의 상단 태그가 우리카드이며 수신 경로는 카카오톡으로 표시된다.
- [ ] 등록된 카드의 카드사와 끝 4자리가 일치하면 기본 롯데카드 대신 해당 카드가 선택된다.
- [ ] 일치 카드가 없거나 여러 장이면 다른 기본 카드를 임의 선택하지 않고 확인 안내를 표시한다.
- [ ] 가계부를 바꾸면 해당 가계부 안에서 카드를 다시 찾는다.
- [ ] 데이터 로딩 중 후보를 열면 기다렸다가 기본 가계부가 선택된다. 실패하면 다시 불러올 수 있다.
- [ ] 편집 중 새로고침이 발생해도 직접 선택한 가계부·카드·수정 금액이 유지된다.
- [ ] 금액 220000은 220,000으로 보이고 입력·삭제·붙여넣기 후에도 실제 금액이 정확하다.
- [ ] 등록 대기 중인 후보는 기존에 저장한 가계부·카드 선택을 그대로 유지한다.
- [ ] 국민카드: 승인금액·가맹점·승인일시가 맞고 누적금액을 거래금액으로 사용하지 않는다.
- [ ] 우리카드: 승인금액·가맹점·승인일시가 맞고 고객 이름을 가맹점으로 사용하지 않는다.
- [ ] 금액·일시·가맹점이 부족한 알림은 ‘검토 필요’로 표시된다.
- [ ] 후보를 검토·수정하고 등록하면 선택 가계부에 한 번만 저장된다.
- [ ] 카카오톡 일반 대화·광고·국민/우리 취소 알림이 후보함에 들어오지 않는다.
- [ ] 여러 메시지의 묶음 알림에서 정상 승인들이 개별 후보로 표시된다.
- [ ] 같은 메시지의 알림 갱신·반복 수신에서 중복 거래가 생기지 않는다.
- [ ] 앱이 백그라운드인 상태와 기기 재부팅 후에도 다음 새 결제를 확인할 수 있다.
- [ ] 알림 수집을 끄면 새 후보를 저장하지 않는다.
- [ ] Fold5의 접기·펼치기와 S25 Ultra에서 후보 수정·등록 화면을 사용할 수 있다.

확인 기록에는 기종, Android/One UI 버전, 수신 앱 이름, 살림온 버전, 재현 순서,
기대/실제 결과만 남긴다. 화면 공유 시 이름·카드번호 등은 가린다.
국민·우리카드는 개별 알림의 식별값으로 등록 재시도 중복을 방지한다. 같은 분에
같은 금액을 결제한 서로 다른 메시지는 별도 후보로 유지한다. 같은 결제가 서로
다른 앱에서 도착하는 경우에는 자동으로 합치지 않으므로 기존 거래와 대조한다.
