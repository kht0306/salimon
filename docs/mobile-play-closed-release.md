# Google Play 비공개 테스트 배포 가이드

## 이번 릴리스 데이터

| 항목             | 값                                        |
| ---------------- | ----------------------------------------- |
| 앱 이름          | 살림온                                    |
| 패키지명         | `com.salimon.app`                         |
| 트랙             | 비공개 테스트                             |
| 버전 이름        | `0.3.7`                                   |
| 버전 코드        | `11`                                      |
| 릴리스 이름      | `0.3.7 (11)`                              |
| 최소 Android API | 29                                        |
| 대상 Android API | 36                                        |
| 업로드 파일      | `dist/mobile/salimon-0.3.7-11.aab`        |
| 체크섬 파일      | `dist/mobile/salimon-0.3.7-11.aab.sha256` |

한국어 릴리스 노트는 아래 문구를 사용한다.

```text
• 비공개 설정을 예산, 캘린더, 거래 내역의 금액까지 확대했습니다.
• 결제 알림 후보 도착 알림의 권한 및 상단 알림 설정 안내를 개선했습니다.
• 앱 안정성을 개선했습니다.
```

## 1. 업로드 전 확인

1. `dist/mobile/salimon-0.3.7-11.aab.sha256`으로 AAB 체크섬을 확인한다.
2. Play Console의 **테스트 및 출시 > 최신 출시 및 번들**에서 현재 가장 높은
   `versionCode`가 10인지 확인한다. 이미 11 이상이면 `apps/mobile/app.json`의
   `versionCode`를 그보다 큰 값으로 올리고 AAB를 다시 만든다.
3. **테스트 및 출시 > 설정 > 앱 무결성**에서 등록된 업로드 인증서가 이번 AAB의
   인증서와 같은지 확인한다. 인증서가 다르면 업로드하지 말고 기존 업로드 키를
   확인한다.
4. 현재 비공개 테스트 트랙에 미완료 초안이나 게시 대기 변경사항이 있는지 확인한다.

## 2. 비공개 테스트 릴리스 생성

1. [Google Play Console](https://play.google.com/console/)에서 **살림온**을 선택한다.
2. **테스트 및 출시 > 테스트 > 비공개 테스트**로 이동한다.
3. 기존 비공개 트랙의 **트랙 관리**를 누른다. 트랙이 없다면 새 트랙을 만든다.
4. **새 버전 만들기**를 누른다.
5. App Bundle 영역에 `dist/mobile/salimon-0.3.7-11.aab`를 업로드한다.
6. Play Console이 표시한 패키지명 `com.salimon.app`, 버전 `0.3.7`, 버전 코드
   `11`, 대상 API `36`을 확인한다.
7. 릴리스 이름에 `0.3.7 (11)`을 입력한다.
8. 한국어 릴리스 노트에 위 문구를 붙여 넣는다.
9. **다음**을 누르고 오류와 경고를 확인한다. 오류는 모두 해결한다.
10. **비공개 테스트 출시 시작** 또는 **검토를 위해 변경사항 전송**을 누른다.
    관리형 게시가 켜져 있으면 검토 승인 뒤 **게시 개요**에서 별도로 게시한다.

## 3. 테스터 배포

1. 비공개 테스트 트랙의 **테스터** 탭에서 기존 이메일 목록 또는 Google 그룹이
   선택되어 있는지 확인한다.
2. 테스터 참여 링크를 복사해 등록된 테스터에게만 전달한다. 비공개 테스트 앱은
   Play 스토어 검색으로 찾지 못할 수 있다.
3. 처리 완료 후 테스트 기기에서 참여 링크를 열고 같은 Google 계정으로 참여한다.
4. Play 스토어에서 살림온을 업데이트한다. 새 버전 반영에는 시간이 걸릴 수 있다.

## 4. 기기 검증

- [ ] 앱 정보에 `0.3.7`이 표시된다.
- [ ] 기존 로그인과 선택 가계부가 유지된다.
- [ ] 비공개 버튼을 끄면 월 합계, 예산, 캘린더, 거래 금액이 모두 가려진다.
- [ ] 다시 켜면 위 금액이 모두 표시된다.
- [ ] 설정에서 **후보 도착 알림**을 켜고 Android 알림 표시 권한을 허용한다.
- [ ] **Android 도착 알림 설정**에서 결제 알림 후보 채널의 알림과 팝업을 허용한다.
- [ ] 롯데카드 테스트 결제 알림 수신 후 후보함에 후보가 생긴다.
- [ ] 같은 시점에 살림온 후보 도착 알림이 상태 표시줄과 상단 팝업에 표시된다.
- [ ] 알림을 누르면 후보함으로 이동한다.
- [ ] 후보 도착 알림을 끄면 후보는 저장되지만 살림온 알림은 표시되지 않는다.

롯데카드 알림 원문, 카드번호, 인증 토큰, 전체 거래 내역은 테스트 기록이나 이슈에
첨부하지 않는다. 실패를 기록할 때는 앱 버전, 기기 모델, Android 버전, 발생 시각,
재현 순서와 민감정보를 가린 화면만 남긴다.

## 5. 문제 발생 시

- **버전 코드 중복:** Play Console의 최고 코드보다 큰 값으로 올려 다시 빌드한다.
- **잘못된 키로 서명됨:** Play Console의 업로드 인증서와 로컬 키를 비교한다. 새 키를
  임의로 만들지 않는다.
- **알림은 후보함에만 저장됨:** 앱의 후보 도착 알림, Android 앱 알림 권한, 결제 알림
  후보 채널의 팝업 설정을 차례로 확인한다.
- **업데이트가 보이지 않음:** 테스터 계정과 참여 상태, 릴리스 상태가 게시됨인지
  확인하고 Play 스토어 캐시가 갱신될 때까지 기다린다.
