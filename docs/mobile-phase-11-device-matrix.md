# 모바일 11회차 기기 안정화 검증표

## 목적

가족 알파 APK를 만들기 전에 접근성, 권한 변화, 프로세스 재생성, 네트워크 장애와
기기별 화면 변화를 검증한다. 실제 카드 알림 원문, 인증 토큰, 가계부 원본은 이
문서와 GitHub에 기록하지 않는다.

## 결함 등급

- **P0:** 데이터 손실·중복 거래·다른 사용자 데이터 노출·로그인 불가·반복 크래시
- **P1:** 주요 거래·후보·정산 흐름을 완료할 수 없거나 권한 상태가 실제와 다름
- **P2:** 우회 가능한 UI·접근성·표시 결함

P0·P1이 하나라도 있으면 12회차 가족 배포를 시작하지 않는다.

## S25 Ultra 확인 결과

- 큰 글꼴 150%와 화면 확대를 함께 적용했을 때 발견한 상단 브랜드 줄바꿈,
  하단 탭 라벨 겹침, 거래 합계 금액 줄바꿈을 보정하고 다시 통과했다.
- 오프라인 새로고침은 마지막 데이터를 읽기 전용으로 유지하며 내부 호스트명이나
  원시 네트워크 예외를 노출하지 않는다.
- 알림 접근 회수 시 설정과 후보함이 권한 복구 필요 상태를 표시하고, 재허용 후
  실제 권한 상태와 일치한다.
- 릴리스 APK 반복 업데이트와 프로세스 재생성 후에도 로그인 세션이 유지됐다.
- 런타임 로그에서 인증 토큰, 서비스 호스트명, 금액, 알림 원문 패턴과 치명적
  오류가 검출되지 않았다.
- 테스트 후 글꼴 1.0, 물리 밀도 600, 자동 회전, Wi-Fi·모바일 데이터 사용,
  비행기 모드 해제, 절전 모드 해제 상태로 복구했다. 알림 후보함과 알림 접근도
  테스트 전의 사용 안 함 상태로 복구했으며 기존 거래는 변경하지 않았다.

## 민감정보 점검 기준

- `adb logcat`과 릴리스 실행 로그에 인증 토큰, 알림 원문, 가맹점, 금액, 가계부
  식별자가 없어야 한다.
- 오류 화면에는 서버 응답 본문이나 데이터베이스 구조가 노출되지 않아야 한다.
- 알림 원문은 Android 암호화 저장소에만 있고 로그·문서·스크린샷에 복사하지 않는다.
- 테스트가 끝나면 변경한 글꼴, 회전, 네트워크, 알림 접근 설정을 원래 상태로
  복구한다.

## 11회차 완료 조건

- 세 기기의 필수 항목이 모두 통과한다.
- P0·P1 결함이 0개다.
- 릴리스 APK가 개발 서버 없이 실행되고 개발 메뉴를 표시하지 않는다.
- 권한 회수·프로세스 재생성 후 후보 보관과 화면 상태가 일치한다.
